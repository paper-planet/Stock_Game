Stock Game Pro 2.3

Major changes:
- Global Markets world monitor redesigned as a dense professional map with exchange session markers, freight/air routes, macro panel, zoom/pan/search/layers.
- 1x time warp now advances one simulated second per real-world second; range remains 1x-10x.
- FIT MAX is a reversible toggle and no longer follows the live ticker, removing fit-mode shimmer.
- Sparse launch combinations use deterministic display-only intraday reconstruction from daily OHLC until genuine intraday bars fill in.
- Starting balances: Easy $50,000; Medium $25,000; Expert $1,000.
- Simplified requested PDT training rule: under $25k, max 3 same-day round trips in a rolling five-business-day week; fourth attempt flags account until equity reaches $25k.
- Account tab displays day trades, PDT status, daily P/L, and portfolio performance ranges ALL/1Y/6M/3M/1M/1W/1D.
- Double-click portfolio chart opens attribution view showing the holdings present during the largest equity moves.
