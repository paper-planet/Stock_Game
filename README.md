STOCK GAME PRO

This build includes UI/gameplay revisions:

CHARTS
- Only the active chart highlights; clicking the active chart again removes the highlight.
- Ticker is shown on every chart.
- Right-click chart includes POP OUT ADVANCED CHART.
- Pop-out charts are freely resizable.

OPTIONS
- Calls and puts are separate panes so ITM/OTM colors can be independent.
- ITM contracts are green; OTM contracts are red; ATM is gold; owned contracts are blue.
- Variables actually add/remove columns instead of leaving hidden columns behind.
- Variables window can be reopened after closing and has RESET ALL COLUMNS.
- Option orders support quantity.
- Spread builder supports per-leg quantity and a payoff preview graph.

ROULETTE
- Larger table and corrected zero hit area.
- Three dozen bets: 1-12, 13-24, 25-36.
- 2:1 column squares at the end of the board.
- Edge clicks create split bets.
- Chips appear as chips with the wager amount on number/outside bet locations.
- Animated wheel/ball with red, black and green zero wheel pockets.
- Last 500 spins are displayed.
- Removed the blue SELECTED CHIP display from the table.

BLACKJACK
- Dealer displays the dealer name instead of the raw (name, color) tuple.
- SPLIT PAIR button added.
- Multiple hands are laid out side-by-side.

MARKET MAP / GLOBAL TRADER / TABLES / NEWS
- Market map uses market-cap-weighted recursive tiles and fits the available window.
- Global market window has OPEN SELECTED IN MARKET FEED, OPTIONS and ADVANCED CHART actions.
- Portfolio and watchlist right-click menus include table variables.
- News has a POP OUT / RESIZE window.

BUILD
- Keep using the included build_windows.bat. It uses python, not py/where.
- The build produces dist\\StockGamePro.exe as a one-file executable.
